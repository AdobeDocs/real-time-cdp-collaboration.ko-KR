# Real-Time CDP Collaboration [!DNL Starter]의 신용 사용 및 소비

이 설명서에서는 Adobe Real-Time CDP Collaboration [!DNL Starter]에 초대된 사용자로 참가할 때 크레딧이 사용되는 방법에 대해 자세히 설명합니다. 신용 사용을 담당하는 사람과 액세스 및 관리에 대한 중요 고려 사항에 대해 자세히 알아보십시오.

Collaboration [!DNL Starter]에 대한 일반적인 개요를 보려면 [Real-Time CDP Collaboration [!DNL Starter] 개요](../overview/starter-overview.md)를 읽어 보십시오.

## 신용 사용 작동 방식 {#credit-usage}

초대를 수락하면 귀하를 초대한 조직에서 귀하의 활동에 대한 모든 크레딧 사용을 다룹니다. 초대자의 계정에서 크레딧이 항상 소비되며, 자신의 계정은 청구되지 않습니다.

## 액세스 및 기대치 관리 {#manage-access-and-expectations}

Collaboration은 크레딧 사용 또는 가용성을 자동으로 적용하지는 **않습니다**. 이것은 다음을 의미합니다.

* 초대받은 사용자는 신용 사용에 대해 논의하기 위해 귀하를 초대한 조직 또는 파트너와 직접 협력해야 합니다.
* 초대 조직은 다음 사항을 결정할 책임이 있습니다.
  * Collaboration 기능에 액세스하고 사용할 수 있는 경우
  * 신용 소비에 대한 제한, 제한 또는 거버넌스

>[!IMPORTANT]
>
> Adobe은 조직 간의 신용 공유 계약을 관리하거나 중재하지 않습니다. 모든 사용 기대는 귀하와 귀하의 초대 파트너 간에 직접 동의해야 합니다.

조직 간 크레딧을 할당하는 방법에 대한 자세한 내용은 [연결 설정 안내서](../connect/establishing-connections.md)의 [크레딧 분할 설정](../connect/establishing-connections.md#credit-split) 섹션을 참조하십시오.

크레딧을 사용하는 활동과 크레딧 사용을 추적하거나 관리하는 방법에 대한 자세한 내용은 [크레딧 사용 활동 추적](./my-activity.md)을 참조하세요.
